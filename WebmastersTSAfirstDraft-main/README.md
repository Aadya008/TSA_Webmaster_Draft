# WebmastersTSAfirstDraft

The site will instruct the user through a gamified platform that is interactive by teaching essential concepts about AI that are not taught in our routine such as school or classes. Furthermore, this will teach how AI is embedded and used for platforms that we don’t realize such as games and educational resources. This will serve as an educational tool by exploring the mechanics and features of AI,  and processes it uses and on things such as training data and algorithmic bias. The website includes aspects that are gamified; it not only includes aspects like multiple choice checkpoints after each module, but it also includes a points system completed by doing both the checkpoint questions and by hidden icons throughout the different tabs. The site will teach Machine Learning Mechanics and what drives it (Module 1) , Prompt Calibration & Fact Verification using the CRAFT framework (Module 2), Algorithmic Bias, Privacy, & Honor Codes (Module 3), and Module 4 will be about the application of the previous 3 modules (using all skills learned and applying them to a real-world scenario). 

The overall look and feel is intended to be interactive, user friendly, easily navigable, and able to provide information and teach in an engaging way that conveys the concepts clearly with understanding (showing the importance of these topics). We are also aiming to make the website more visually appealing so it can engage the user and spark interest to learn and complete all the modules. Once all modules are completed, the takeaway would be for the users to reflect on what they have learned and gained an understanding in what drives the process of AI and how it works, while applying critical thinking and problem solving.
